# ARCHITECTURE.md - 시스템 구성도

## 1. 전체 시스템 플로우차트

```
┌─────────────────────────────────────────────────────────────┐
│                        사용자 브라우저                        │
│                    (index.html + JS)                         │
└───────────────────────────┬─────────────────────────────────┘
                            │ POST /query { "question": "..." }
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                     FastAPI 서버 (api.py)                    │
│                                                              │
│  1. 질문 수신                                                │
│  2. SentenceBERT로 질문 → 벡터(768차원) 변환                 │
│  3. Qdrant 검색 → 유사 규제 조항 Top 3 추출                  │
│  4. 프롬프트 템플릿에 조항 주입                               │
│  5. OpenAI API 스트리밍 호출                                 │
│  6. SSE로 토큰 단위 응답 전송                                 │
└──────────┬──────────────────────────┬───────────────────────┘
           │                          │
           ▼                          ▼
┌──────────────────┐       ┌──────────────────────┐
│   Qdrant DB      │       │    OpenAI API         │
│  (qdrant_db/)    │       │  (gpt-4o-mini)        │
│                  │       │                       │
│  - 벡터 저장     │       │  - 리스크 판단        │
│  - 유사도 검색   │       │  - 스트리밍 응답      │
└──────────────────┘       └──────────────────────┘
```

## 2. RAG 파이프라인 상세

```
[오프라인 - 1회 실행]
───────────────────────────────────────────────────
regulations.csv
    │
    ▼
SentenceBERT 임베딩
("제목: ... | 내용: ..." → float[768])
    │
    ▼
Qdrant 저장
(id, vector, payload{title, content, category})


[온라인 - 요청마다 실행]
───────────────────────────────────────────────────
유저 질문: "HBM3 칩을 중국에 수출해도 되나요?"
    │
    ▼
SentenceBERT 임베딩 → query_vector (float[768])
    │
    ▼
Qdrant 코사인 유사도 검색 (limit=3)
    │
    ▼
검색 결과 (Top 3 규제 조항)
 - "미국 EAR 반도체 수출 통제..."
 - "미국 칩스법 보조금 조건..."
    │
    ▼
프롬프트 조립 (RAG 핵심)
┌─────────────────────────────────────┐
│ 시스템: 당신은 반도체 수출 규제     │
│         전문가입니다.               │
│                                     │
│ 컨텍스트:                           │
│ [검색된 규제 조항 3개 삽입]         │
│                                     │
│ 질문: HBM3 칩을 중국에 수출해도    │
│       되나요?                       │
└─────────────────────────────────────┘
    │
    ▼
OpenAI API (stream=True)
    │
    ▼
토큰 단위 스트리밍
"HBM3 칩의 경우..." → "미국 EAR 규정에..." → "따라 금지됩니다..."
    │
    ▼
SSE (text/event-stream)
    │
    ▼
브라우저에 실시간 타이핑 효과로 표시
```

## 3. 컴포넌트별 역할 요약

| 파일 | 역할 | 실행 시점 |
|------|------|-----------|
| `ingest.py` | CSV → 벡터 변환 → Qdrant 저장 | 최초 1회 |
| `search.py` | 벡터 검색 테스트 (CLI) | 개발/테스트 시 |
| `api.py` | FastAPI 서버, RAG 파이프라인 통합 | 서버 실행 시 |
| `index.html` | 채팅 UI, SSE 수신 | 브라우저 접속 시 |
| `qdrant_db/` | 벡터 데이터 저장소 | 상시 |
