## 2. Qdrant 벡터 DB 스키마

**컬렉션명:** `semiconductor_regulations`

### 벡터 설정
| 항목 | 값 | 설명 |
|------|----|------|
| `size` | `768` | `jhgan/ko-sroberta-multitask` 모델 출력 차원 |
| `distance` | `COSINE` | 유사도 측정 방식 (코사인 유사도) |

### 포인트 구조
```json
{
  "id": 1,
  "vector": [0.23, -0.11, 0.87, ...],  // float 768개
  "payload": {
    "title": "미국 EAR 반도체 수출 통제",
    "content": "미국 상무부는 14나노 이하 시스템 반도체 제조 장비의 중국 수출을 원칙적으로 금지한다.",
    "category": "수출통제"
  }
}
```

### 임베딩 입력 형식
```
"제목: {title} | 내용: {content}"
```
> 제목과 내용을 합쳐서 임베딩 → 의미 풍부하게 표현
