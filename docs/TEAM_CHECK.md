# 팀원 논의 사항 정리

> 개발 시작 전 팀원과 확인이 필요한 항목들입니다.

---

## 1. 🔧 환경 세팅 재설치 필요 (즉시)

`requirements.txt`에 패키지를 추가했습니다.
팀원 로컬에서 아래 명령어를 다시 실행해주세요.

```bash
pip install -r requirements.txt
```

**추가된 패키지:**
- `fastapi`
- `uvicorn`
- `openai`
- `python-dotenv`

그리고 루트에 `.env` 파일을 직접 만들어서 API 키를 넣어주세요.

```
OPENAI_API_KEY=sk-...
```

---

## 2. 📊 regulations.csv 데이터 개수 확인

`inspect_db.py`에서 현재 `limit=10`으로 설정되어 있습니다.
데이터가 10개를 초과하면 나머지가 출력되지 않습니다.

**확인 필요:**
- regulations.csv에 데이터가 총 몇 개인가요?
- 10개 초과라면 `inspect_db.py` 수정이 필요합니다.

---

## 3. 🏗️ api.py 역할 분담 경계선 확인

충돌 없이 작업하려면 **누가 어디까지 작성하는지** 미리 합의가 필요합니다.

| 파트 | 담당 | 내용 |
|------|------|------|
| FastAPI 기본 구조 | 동훈 | 서버 뼈대, 라우터 세팅 |
| Qdrant 검색 연결 | 동훈 | search.py 로직 → api.py로 이식 |
| 프롬프트 설계 | 동훈 | 규제 조항 주입 템플릿 작성 |
| OpenAI API 연결 | 팀원 | gpt-4o-mini 호출 |
| SSE 스트리밍 | 팀원 | 실시간 응답 전송 구현 |
| index.html | 팀원 | `templates/` 폴더에 프론트엔드 작성 |

**논의 포인트:**
- 동훈이 어디까지 작성하고 팀원에게 넘길지 정확한 지점 합의
- `api.py` 하나의 파일을 둘이 작성하는 만큼, 작업 순서도 정해야 함
  - 예: 동훈이 뼈대 + 검색 먼저 → PR → 팀원이 OpenAI + SSE 추가
